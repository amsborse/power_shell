# Yogi Artist Terminal Theme

This folder contains the beautiful "Yogi Artist" terminal profile for PowerShell.

## Features
- **Mindful Prompt**: Shows the time, clean path, and git branch with calming colors.
- **`today` command**: Gently reminds you of today's date.
- **`breathe` command**: A 12-second mindful breathing exercise right in your terminal.
- **`yrun` command**: Run a command and beautifully log its execution time and exit status.
- **`yogi-theme-info`**: Check the installation status of your terminal profile.

## Installation
The profile block can be automatically injected into your `$PROFILE` by running:
```powershell
yogi theme install
```

## Removal
To safely remove the profile block and leave the rest of your `$PROFILE` intact, run:
```powershell
yogi theme remove
```
